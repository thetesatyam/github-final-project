# Paradise Nursery Shopping Application

## Project Name
**Paradise Nursery**

Paradise Nursery is a React and Redux shopping cart application for an online houseplant store. Users can browse plants by category, add plants to a cart, change quantities, remove items, and view dynamically calculated totals.

## Main Features
- Responsive landing page with company name and Get Started button.
- About Us section with company information.
- Three plant categories with six unique plants in each category.
- Plant thumbnails, names, prices, and descriptions.
- Add to Cart buttons that disable after adding.
- Dynamic cart item count.
- Shared navigation between Home, Plants, and Cart.
- Redux Toolkit cart state management.
- Increase/decrease quantity controls.
- Remove-from-cart functionality.
- Dynamic item totals and grand total.
- Checkout button displaying a Coming Soon message.
- Continue Shopping button returning to the plant listing.

## Technologies
- React
- React Router
- Redux Toolkit
- React Redux
- Vite
- CSS3

## Run Locally
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.
